# 🤖 دليل تشغيل Wasel Admin MCP Server مع هيرميز إيجنت (Hermes Agent)

يوفر خادم **Wasel Admin MCP Server** جسراً ذكياً يتيح لـ **Hermes Agent** وأي عميل يدعم بروتوكول سياق النماذج (Model Context Protocol - MCP) التحكم الكامل في تطبيق المدير وإدخال وحذف البيانات الحية (متاجر، وجبات، كباتن، تسويات) لمنظومة واصل نالوت بالأوامر الصوتية أو النصية الطبيعية.

---

## 🛠️ 1. مواصفات الخادم وطريقة الربط (Configuration)

تم تسجيل الخادم مسبقاً في ملف إعدادات الـ MCP العالمي للجهاز:
`C:\Users\kalifa\.gemini\config\mcp_config.json`

### كود التكوين المعتمد في Hermes / Claude Desktop / Antigravity:
```json
{
  "mcpServers": {
    "wasel-admin-mcp": {
      "command": "node",
      "args": [
        "c:\\Users\\kalifa\\Desktop\\wasel-app\\wasel-admin-mcp\\index.js"
      ],
      "env": {
        "WASEL_BACKEND_URL": "https://wasel-nalut.onrender.com/api/v1",
        "WASEL_ADMIN_KEY": "9832"
      }
    }
  }
}
```

## 📋 2. دليل الأدوات المتاحة (MCP Tools Catalog)

| اسم الأداة (Tool Name) | الوظيفة والوصف | المدخلات الأساسية |
|---|---|---|
| `wasel_admin_get_overview` | قراءة مؤشرات الأداء الحية (GMV، عدد الطلبات، الكباتن المتاحين، الكاش المعلق، المتاجر) | لا توجد مدخلات |
| `wasel_admin_list_stores` | جلب كافة المتاجر والمطاعم والصيدليات المسجلة في نالوت مع بيانات الدخول | لا توجد مدخلات |
| `wasel_admin_add_store` | إضافة متجر جديد، وتوليد حساب دخول فوري للتاجر (هاتف + PIN)، مع توليد 4 وجبات نموذجية تلقائياً | `name`, `type`, `phone`, `district`, `base_delivery_fee_lyd`, `auto_starter_menu` |
| `wasel_admin_delete_store` | حذف متجر نهائياً من قاعدة البيانات والمنظومة | `store_id` |
| `wasel_admin_toggle_store_status` | فتح أو إغلاق المتجر مؤقتاً في تطبيق الزبون | `store_id`, `is_open` |
| `wasel_admin_list_products` | عرض قائمة الوجبات والأسعار لمتجر معين أو لجميع المتاجر | `store_id` (اختياري) |
| `wasel_admin_add_product` | إضافة صنف أو وجبة جديدة لقائمة المتجر مع السعر والتصنيف | `store_id`, `name`, `price`, `category`, `description` |
| `wasel_admin_delete_product` | حذف وجبة أو صنف من قائمة المتجر | `product_id` |
| `wasel_admin_list_drivers` | عرض أسطول كباتن نالوت مع رصيد العهدة النقدية (COD) وحالة الاتصال | لا توجد مدخلات |
| `wasel_admin_add_driver` | تسجيل كابتن توصيل جديد وتوليد بيانات دخوله لتطبيق Wasel Captain | `full_name`, `phone`, `vehicle_type`, `plate_number`, `max_cod_limit_lyd` |
| `wasel_admin_delete_driver` | حذف كابتن نهائياً من الأسطول وإيقاف حسابه | `driver_id` |
| `wasel_admin_settle_driver_cash` | تسوية واستلام العهدة النقدية وتصفير حساب الكابتن | `driver_id` |
| `wasel_admin_batch_import` | استيراد بيانات ضخمة دفعة واحدة (متاجر، أصناف، كباتن) في ثوانٍ | `stores`, `products`, `drivers` |
| `wasel_admin_purge_all` | تطهير البيانات الوهمية بالكامل وتصفير المنظومة (يتطلب PIN: 9832) | `admin_pin` |

## 🗣️ 3. أمثلة على أوامر نصية مباشرة لهيرميز (Prompts for Hermes)

يمكنك التحدث مع هيرميز إيجنت باللغة العربية البسيطة وسيقوم هو باستدعاء الأدوات تلقائياً:

### أ) إضافة المتاجر والمطاعم:
> **أنت:** "يا هيرميز، أضف مطعم جديد في نالوت باسم (مطعم قصر الجبل) في شارع أفريقيا، نوعه مطعم وكافيه، وهاتف التاجر 0914443322 مع قائمة أصناف نموذجية أولية."
> 
> **هيرميز ينفذ:** يستدعي `wasel_admin_add_store` وينشئ المتجر ويولد له 4 وجبات جاهزة وحساب دخول فوري.

### ب) إضافة الوجبات والأصناف:
> **أنت:** "أضف وجبة جديدة لمطعم قصر الجبل باسم (صحن مشكل كباب وشيش طاووق) بسعر 28 دينار في قسم المشويات مع وصف (لحم وطني طازج مع سلطات وخبز تنور)."
> 
> **هيرميز ينفذ:** يستدعي `wasel_admin_add_product`.

### ج) تسجيل كباتن التوصيل:
> **أنت:** "سجل كابتن جديد باسم (مراد مسعود النالوتي)، رقم الهاتف 0927778899، يقود سيارة هيونداي فيرنا بلوحة نالوت 14-55432 وسقف الكاش 300 دينار."
> 
> **هيرميز ينفذ:** يستدعي `wasel_admin_add_driver` ويولد رمز الـ PIN وبيانات تسجيل الدخول لتطبيق الكابتن.

### د) إدارة العهدة النقدية ومتابعة المبيعات:
> **أنت:** "اعرض لي أسطول الكباتن ومن معه كاش معلق الآن، واعرض لي إجمالي مبيعات اليوم."
> 
> **هيرميز ينفذ:** يستدعي `wasel_admin_list_drivers` و `wasel_admin_get_overview` ويعطيك تقريراً تحليلياً بالدينار الليبي.

### هـ) تسوية عهدة كابتن:
> **أنت:** "الكابتن مراد قام بتوريد الكاش نقداً لمقر الإدارة، قم بتسوية عهدته النقدية."
> 
> **هيرميز ينفذ:** يستدعي `wasel_admin_settle_driver_cash`.

### و) الإدخال الشامل دفعة واحدة (Batch Import):
> **أنت:** "يا هيرميز، أريد إدخال 3 صيدليات و5 مطاعم و10 كباتن دفعة واحدة لمدينة نالوت، إليك البيانات التالية: [...]"
> 
> **هيرميز ينفذ:** يستدعي `wasel_admin_batch_import` وينشئ الكل دفعة واحدة في ثانية واحدة.

## 🚀 5. كيف يتم حفظ البيانات وتوزيعها بين التطبيقات؟
- عندما يقوم هيرميز بتنفيذ أي أداة، يتم إرسال البيانات فوراً إلى:
  1. **الخادم السحابي الحي (Render Production Backend):** لتحديث الذاكرة الحية وتنبيه التطبيقات المتصلة عبر Socket.IO فوراً.
  2. **سحابة Supabase Cloud:** للحفظ الدائم والموثوق 24/7.
  3. تظهر البيانات في **تطبيق المدير (Wasel Admin)** وفي **تطبيق التاجر (Wasel Merchant)** وفي **تطبيق الكابتن (Wasel Captain)** وفي **تطبيق الزبون (Wasel Nalut)** لحظياً وبدون الحاجة لإعادة تشغيل الخوادم!
